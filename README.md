# LITVINAVISAS — сайт на React / Next.js

Многостраничный сайт визового сопровождения Екатерины. Next.js + TypeScript, светлая/тёмная тема, адаптивная навигация, параллакс и форма обращения.

## Просмотр на GitHub Pages

**Демо:** https://larekk.github.io/litvinavisas/

GitHub Pages — это отдельный адрес для просмотра React-версии. Оригинальный адрес сайта на Tilda **не изменён**, свой домен **не подключён** и файл `CNAME` отсутствует.

Для первой публикации откройте **Settings → Pages → Build and deployment → Source → GitHub Actions**. Workflow `.github/workflows/deploy.yml` будет автоматически публиковать статическую сборку при каждом push в `main`. Ход публикации виден во вкладке **Actions**.

При настройке сборки в GitHub Actions переменная `NEXT_PUBLIC_BASE_PATH=/litvinavisas` добавляет префикс только к путям демоверсии на GitHub Pages. Она **не меняет** URL сайта на Tilda и не добавляет домен.

## Локальный запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Для полной проверки: `npm run build` и `npm run typecheck`. Требуется Node.js 22 (поддерживается Node >=20.9).

## Структура

- `src/app/` — маршруты и глобальные стили
- `src/components/` — шапка, футер, форма, переключатель тем и параллакс
- `src/lib/data.ts` — направления и содержимое региональных страниц
- `public/images/` — изображения
- `PAGE_MAP.md` — сопоставление страниц Tilda и React-маршрутов
- `.github/workflows/deploy.yml` — автоматическая сборка и публикация

## Ограничения статического хостинга

GitHub Pages не запускает Next.js API и серверные функции. Поэтому проект настроен на `output: "export"` и собирается в папку `out/`.

**Форма заявок:** если сервис приёма обращений пока не настроен, кнопка «Подготовить письмо» открывает черновик email. Это **не равно** отправленной заявке. Для настоящей отправки можно подключить Formspree, установить публичную переменную `NEXT_PUBLIC_CONTACT_FORM_ENDPOINT` в GitHub (**Settings → Secrets and variables → Actions → Variables**) и запустить workflow повторно. Не помещайте секретные API-ключи в переменные `NEXT_PUBLIC_*`.

Адрес `vizera@gmail.com` остался как ранее указанный контактный email; его не следует менять без подтверждения нового адреса. Telegram: `@KK4TI`.

## Что требуется до полноценного запуска

1. Проверить и перенести юридические документы. Сейчас политика и оферта ведут к существующим документам на Tilda, а договор об оказании услуг содержит временную заглушку.
2. Подключить реальный сервис приёма заявок, если нужна прямая отправка из формы.
3. Заменить временную фотографию первого экрана оригиналом, а внешнюю фотографию параллакса — собственным файлом.
4. Проверить реквизиты, контакты, мобильную вёрстку, скорость, доступность и SEO. Пока сайт помечен `noindex` на время разработки.

## Дизайн

Светлая и тёмная темы переключаются в шапке, выбор хранится в `localStorage` (`litvinavisas-theme`). По умолчанию тёмная. Палитра и базовая вёрстка: `src/app/globals.css`, тёмные переопределения: `src/app/dark-theme.css`.
